# playround

Small personal apps, one folder each. Their ports are in [PORTS.md](PORTS.md).

| Project | What it does |
|---|---|
| [app-gateway](app-gateway/README.md) | Serves several apps behind one public port |
| [chatlog-viewer](chatlog-viewer/README.md) | Reads Claude Code and Codex session logs in the browser |
| [collection-tree](collection-tree/README.md) | Browsable HTML trees of selected collection folders, built from Everything |
| [epub-finder](epub-finder/README.md) | Desktop full-text search over a folder of EPUBs |
| [lnlib](lnlib/README.md) | Bookshelf and in-browser reader for a light novel and manga collection |
| [usb-wake](usb-wake/README.md) | ESP32 Wi-Fi Wake-on-LAN controller with a free Cloudflare relay |
